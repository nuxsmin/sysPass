# Contributing

## Where to post

| Need | Where |
| --- | --- |
| Bug, with version and steps to reproduce | Issue (bug report template) |
| Feature request that solves a concrete problem | Issue (feature request template) |
| Question or how-to | [Discussions, Q&A](https://github.com/nuxsmin/sysPass/discussions/new?category=q-a) |
| Early idea or general discussion | [Discussions, Ideas](https://github.com/nuxsmin/sysPass/discussions/new?category=ideas) |
| Security vulnerability | Private report, see [SECURITY.md](SECURITY.md). Never a public issue |

## Issue triage

- New issues start with `needs-triage`. Maintainers replace it with a triage label after review.
- Issues that lack the information needed to reproduce or evaluate them are labelled `needs-info`.
- Questions and ideas filed as issues are closed with a link to the matching Discussions category. Continue the conversation there.
