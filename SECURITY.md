# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.2.x   | :white_check_mark: |
| < 3.2   | :x:                |

## Reporting a Vulnerability

Please, before disclosing any vulnerability, report it privately through [GitHub private vulnerability reporting](https://github.com/nuxsmin/sysPass/security/advisories/new). Do not open a public issue or discussion for it.

If private reporting is unavailable, email security@syspass.org.
